🚀 五分鐘快速建立活動

只要五個步驟，您就能從零開始建立一個完整的線上報名活動。以下是從登入到活動上線的完整流程：

登入→建立活動→上傳規則→設定梯次→海報+AI配色→儲存→開放報名
1
登入管理後台 — 點擊網頁右上角 🔑 活動管理者登入，輸入帳號與密碼。首次使用請先點擊「✨ 申請新帳號」完成註冊流程（詳見帳號章節），帳號開通後系統會自動寄送一組免費授權碼至您的信箱。

② 選擇「活動分類」：競賽、夏令營、研討會、工作坊、展覽、教育訓練

💡 專業提示：若您的活動說明是純文字，點擊 🔄 自動轉換為 HTML，系統會自動加入表情符號 emoji、將網址轉為美觀按鈕、自動分段。轉換適用於「活動說明」「付款說明」「檔案上傳說明」三個欄位。

🚀 Set Up in 5 Minutes

Just five steps to create a fully functional online registration event from scratch:

Login→Create→Upload Rules→Set Sessions→Poster + AI Color→Save → Go Live
1
Log In — Click 🔑 Activity Manager Login (top-right). First-time users: click "✨ Create Account" to register. A free license code is emailed upon activation.
2
Create Event — Click + Create Activity. Enter event name, choose category (Competition/Camp/Seminar/Workshop/Exhibition/Training) and type (individual or team, with or without coach/parent/instructor).
3
Add Content — Upload rules PDF → Upload poster image (max 10MB) → Click 🎨 AI Color to auto-generate a matching 5-color theme → Fill in event description (use 🔄 Auto-Convert to HTML for plain text).
4
Configure Rules — Set sessions (at least one start + end date), payment methods (transfer/card/cash/online), participant fields (dietary, T-shirt, etc.), and groups with age limits as needed.
5
Go Live! — Click 💾 Save Settings → Toggle registration to Open → Copy share link → Done! 🎉
💡 Pro Tip: Click 🔄 Auto-Convert to HTML to auto-format plain text with emojis and styled URL buttons. Works for "Activity Description", "Payment Note", and "File Upload Description".

授權碼類型

建立新活動時系統會自動扣除授權額度。RegMaster 提供兩種授權碼：

類型圖示說明與計費方式
訂閱型
(Subscription)		📆在有效期限內（如 1 年）可無限次建立活動。啟用多組訂閱授權碼時，系統自動找出最晚到期日並向後疊加時間，確保您的權益不浪費。
次數型

⚠️ 當訂閱即將到期（剩餘 30 天內）或次數僅剩最後 1 次時，系統會自動寄發 Email 提醒。

欄位說明

每個活動至少需要設定一組梯次，每組梯次包含「開始日期」和「結束日期」。

若您的活動有多個組別（如國小組、國中組、高中組、普高組、技高組、大專／社會組、教師組、公開組等），可在此區塊設定。

❓ 常見問題

設定修改後沒生效？

請確認有點擊最下方的 💾 儲存設定 按鈕。修改後未儲存的設定不會生效。這是最常見的問題！

建立活動失敗，跳出「需要授權」？

代表您的授權碼已過期或次數額度已用盡。請至管理首頁點擊「🔑 管理授權碼」輸入新的授權代碼。

AI 配色功能失敗？

請確認已上傳海報圖片。若遇到 API 擁塞，請稍等 1 分鐘後重試。若仍無法使用，可能是 AI 金鑰未正確設定，請聯繫平台管理者。

AI 助理無法回答問題？

AI 的知識來源為規則 PDF 和活動說明。若尚未上傳規則 PDF 或活動說明為空，AI 可能無法提供有效回答。請確認：

  • 已上傳規則/規章 PDF
  • 活動說明欄位已填寫內容
  • 系統開關中 AI 助理已開啟

首頁看不見活動海報？

請確認已上傳海報圖片檔案（JPG/PNG/GIF/WebP，上限 10MB）。

報名者說看不到報名按鈕？

請確認：

  • 系統開關中「報名」已切換為「開放」
  • 截止日期尚未到期
  • 若有設定定時開放，開放日期是否已到達
  • 若有設定最大組數，名額是否已滿（且未啟用備取）

報名者如何修改已提交的資料？

請報名者至活動報名頁點擊「🔐 登入修改」→ 輸入報名編號與密碼 → 修改資料後重新送出。

如何查詢報名狀態？

在報名頁面的「🔍 查詢報名」區塊，輸入報名編號（格式如 T1A2B3C）即可查詢。

匯出的 CSV 在 Excel 中顯示亂碼？

RegMaster 匯出的 CSV 已內含 BOM 標記，正常情況下 Excel 可直接開啟且中文正確顯示。若仍有問題，請嘗試以 UTF-8 編碼開啟。

群發通知沒有送達？

請確認：

  • 報名者在報名時有填寫 Email 欄位
  • 信件可能進入垃圾郵件資料夾，請報名者檢查
  • 群發信件使用 BCC 方式發送，收件者不會看到其他人的 Email

可以修改活動分類或類型嗎？

活動分類和活動類型在建立時即決定，建立後無法修改。若需變更，建議使用「複製活動」功能建立新活動，再調整設定。

忘記登入密碼怎麼辦？

在登入視窗點擊「忘記密碼？」→ 輸入註冊時的 Email → 系統會自動發送新密碼到您的信箱。

如何更換海報圖片？

直接在設定頁面重新上傳新的海報圖片即可，新圖會覆蓋舊圖。上傳後建議重新點擊 🎨 AI 配色 更新配色主題。

如何設定梯次為複選模式？

首先確認活動已建立 2 個以上的梯次（點擊「＋ 增加梯次」），梯次區右側會自動出現「單選 / 複選」下拉選單，將其切換為「複選」後點擊 💾 儲存設定 即可。報名者會看到 Checkbox 勾選框，可同時選擇多個梯次。

複選梯次的 Google 日曆怎麼運作？

報名者選擇多個梯次並完成報名後，點擊「📅 加入行事曆」會依序為每個選中的梯次開啟一個 Google Calendar 視窗，每個梯次獨立建立日曆事件。

檔案上傳設為「選填」後儲存，重新開啟還是顯示「必填」？

此問題已在 v5.3 修復。若仍遇到問題，請確認後端程式碼已更新為最新版本（index.js 白名單需包含 fileUploadLevel）。

管理介面右下角的紫色 ⚙️ 按鈕是什麼？

那是「管理 AI 助理」，專為活動管理員和系統管理員設計。它可以回答所有關於 RegMaster 平台設定與操作的問題。知識來源包含操作手冊和系統功能說明。點擊即可開啟對話視窗。

儲存設定後離開仍跳出「尚未儲存」提示？

此問題已在 v5.3 修復。儲存成功後系統會正確重置變更追蹤狀態，不再誤報未儲存的提示。

系統管理員如何篩選操作日誌？

進入「📋 操作日誌」頁面後，頂部提供四種篩選條件：

  • 操作者：輸入帳號關鍵字即時篩選
  • 動作：下拉選單自動列出所有出現過的動作類型（如「建立活動」「確認付款」「報名」等）
  • 日期範圍：選擇開始與結束日期，只顯示該期間的紀錄

篩選條件可組合使用，下方會顯示「顯示 X / Y 筆」提示。點擊「✕ 清除篩選」可一鍵還原。

Dashboard 的報名情況 Tab 如何使用歷史資料對比？

操作步驟：

  • 在上屆活動的 Dashboard 報名情況 Tab 中，點擊「📤 匯出本次每日報名數 CSV」
  • 在本屆活動的 Dashboard 報名情況 Tab 中，點擊「📥 匯入過往每日報名數 CSV」並選擇上屆的 CSV 檔案
  • 將 X 軸切換為「倒數日」，即可看到歷史趨勢以灰色虛線疊加在當前數據上

如何嵌入報名表到自己的網站？

在活動設定頁面的「分享連結」區塊，點擊「🖥 內嵌程式碼」按鈕，系統會產生完整的 iframe HTML 程式碼，複製後貼入您的網頁即可嵌入報名表。

多人團隊報名，學員人數有上限嗎？

系統本身不限制學員人數，但建議根據實際活動需求在活動說明中說明人數限制。報名者可在報名表中動態新增學員。

❓ Frequently Asked Questions

Settings not taking effect?

Make sure you clicked 💾 Save Settings at the bottom. This is the most common issue!

"License Required" error?

Your license has expired or credits are exhausted. Click "🔑 Manage License" on the admin home to enter a new code.

AI Color analysis failed?

Ensure you've uploaded a poster image. Wait 1 minute and retry if the API is busy.

AI Assistant can't answer questions?

Upload a rules PDF and fill in the activity description. The AI draws knowledge from these sources.

Poster not showing on homepage?

Confirm you've uploaded a poster image (JPG/PNG/GIF/WebP, max 10MB).

Registrants can't see the registration button?

Check: registration toggle is "Open", deadline hasn't passed, scheduled open date has arrived, capacity isn't full.

How can registrants edit submitted data?

Click "🔐 Login / Edit" → Enter registration ID and password → Edit and resubmit.

How to check registration status?

Enter the registration ID (e.g. T1A2B3C) in the "🔍 Look Up" section.

CSV shows garbled characters in Excel?

RegMaster CSV includes BOM encoding for Excel compatibility. If issues persist, try opening with UTF-8 encoding.

Bulk notifications not delivered?

Ensure registrants provided email addresses. Check spam folders. BCC is used for privacy.

Can I change activity category or type after creation?

No — these are set at creation. Use "Duplicate Activity" to create a new one with different settings.

Forgot login password?

Click "Forgot Password?" → Enter your email → A new password is sent automatically.

How do I set up multi-select sessions?

Create 2+ sessions → A "Single / Multi" dropdown appears next to the session label → Switch to "Multi" → Save Settings. Registrants will see checkboxes to select multiple sessions.

How does Google Calendar work with multi-select sessions?

After registration, clicking "📅 Add to Calendar" opens a separate Google Calendar window for each selected session.

File upload "Optional" not saving correctly?

Fixed in v5.3. Ensure your backend (index.js) is updated to the latest version with fileUploadLevel in the config whitelist.

What is the purple ⚙️ button in the admin interface?

That's the Admin AI Assistant — designed for activity managers and system admins. It answers questions about RegMaster platform settings and operations using the operation manual as its knowledge base.

"Unsaved changes" alert after saving?

Fixed in v5.3. The dirty tracking flag now resets correctly after a successful save.

How do system admins filter audit logs?

The audit log page provides filters for: operator (text search), action type (dropdown auto-populated from log data), and date range. Filters combine and show "Showing X / Y entries". Click "✕ Clear" to reset.

How to compare registration trends across years?

Export daily registration CSV from last year's Dashboard → Import it into this year's Dashboard → Switch X-axis to "Countdown Days" to see historical overlay as a dashed gray line.

How to embed the registration form on my website?

In the share link section, click "🖥 Embed Code" to get a ready-to-use iframe HTML snippet. Copy and paste it into your webpage.
